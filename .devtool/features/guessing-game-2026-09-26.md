# Gamedle-style guessing game

Guess-the-super modes using catalog data: powers quiz, blurred-image reveal, etc. Scoring: faster correct = more points (10 for first-try success, decreasing per error, fail = 0). Arcade-style leaderboard: top-10 display, repeat names allowed, submitter name rules (length, profanity filter), owner-managed blacklist for removals, captcha on submit against bots. Reference: https://www.gamedle.wtf/?lang=en
